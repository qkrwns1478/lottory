# LOTTORY 요구사항 정의서

## 1. 서비스와 도메인 선정 근거

LOTTORY는 회차별 추첨 기록과 외부 법령에서 근거를 검색해 답변하고 **문서 제목과 원문 URL**을 표시한다. 회차별 정확 조회와 통계는 Python 코드로 CSV를 읽어 처리하고, 회차 메타데이터와 외부 문서는 서로 다른 Vector DB 컬렉션에 색인한다.

| 항목 | 내용 |
|---|---|
| 항목 단위 | 로또 6/45의 **1개 추첨 회차 = 1개 항목** |
| 항목 출처 | [캐시로지 회차별 CSV](https://cashlogy.kr/lotto/excel.csv) ([안내 페이지](https://cashlogy.kr/lotto/excel)) |
| 데이터 규모 | 2026-10-17 기준 안내 범위 **1~1246회**, 최대 1,246개 회차 |
| 수집·적재 규모 | 원본 고유 회차 **1,246건** 검증, 최근 **200개 회차(1047~1246회)** 적재 |
| 최소 데이터 요건 | **검증된 고유 회차 100건 이상** |
| 외부 문서 | [국가법령정보센터](https://www.law.go.kr/)의 「복권 및 복권기금법」, 「소득세법」 등 관련 법령 조문 |
| 공식 대조 | [동행복권 당첨결과](https://www.dhlottery.co.kr/lt645/winNumber) |

### 자료 이용 조건

| 출처 | 이용 방식 | 조건 및 출처 표시 |
|---|---|---|
| 캐시로지 CSV | 비영리 교육용 단일 파일 다운로드·로컬 가공·색인 | 제공 페이지 **CC BY 4.0** 표시, 캐시로지 및 원천 발표 동행복권 표기 |
| [캐시로지 이용약관](https://cashlogy.kr/terms) | 수집 방식 적용 | 웹페이지 대량 크롤링·상업적 재배포 제외 |
| 국가법령정보센터 | 법령 조문 원문 검색·수집·색인 | 법령명, 조문, 시행일, 원문 URL 표기 |
| [국세청 기타소득 원천징수세율 안내](https://d.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7893&mi=6457) | F2016의 공공기관 안내문 본문 발췌·색인 | 비영리 교육용 관련 부분만 사용하고 출처·원문 URL·확인일·이용 범위 기록. 개별 이용조건은 원문 확인 |
| 동행복권 | 결과 대조·공식 링크 | 홈페이지 안내문 전문을 수집 대상으로 사용하지 않음 |
| LOTTORY 작성 설명문 | 출처를 확인한 사실을 검색용으로 재구성 | `structured_summary`로 표시하고 참고한 자료 URL 기록 |

### 근거가 필요한 질문

| 질문 | 근거 및 처리 기준 |
|---|---|
| “1100회 1등 당첨금과 1등 당첨 게임 수는?” | 해당 회차의 CSV 기록과 동행복권 공식 대조 링크 |
| “최근 100회 중 22번이 몇 번 나왔어?” | 실제 **100개 회차 전체**의 번호를 Python으로 집계 |
| “2026년 9월에 22번이 나온 회차는?” | 날짜와 번호 조건을 모두 만족하는 회차만 반환 |
| “당첨금 수령기한은?” | 적용 시점의 법령 조문과 원문 URL |
| “10억 원의 예상 실수령액은?” | 적용 세율·공제 조건의 법령 근거와 계산 과정 |
| “자주 나온 번호를 고르면 다음에 더 유리해?” | 확률 근거에 따라 과거 빈도와 다음 회차 확률의 차이를 안내 |
| “9999회 당첨금은?” | 해당 회차 자료가 없으면 근거 부족 응답 |

## 2. 기능적 요구사항

### 2.1 필수 기능 (F2001~F2012)

| 번호 | 분류 | 요구사항명 | 요구사항 상세 | 우선순위 | 검증 기준 |
|---|---|---|---|---|---|
| F2001 | 데이터 | 회차 메타데이터 적재 | CSV에서 회차 목록을 로드하고 **1회차를 검색 텍스트 1개**로 구성한다. | 필수 | 필수 필드 검증 및 고유 회차 **100건 이상** |
| F2002 | 색인 | 메타데이터 색인(RAG 1) | 회차 텍스트를 임베딩하여 `lotto_rounds`에 색인한다. | 필수 | 입력 회차 수·컬렉션 ID/건수 일치, 중복 방지 |
| F2003 | 프롬프트 | 검색어 추출(프롬프트 1) | 선택 회차와 질문에서 외부 검색어, 의도, 정확 필터, 계산 필요 여부를 추출한다. | 필수 | JSON 스키마 및 번호·회차·날짜 범위 검증 |
| F2004 | 수집 | 외부 문서 검색·선별(프롬프트 2) | 법령 검색 API에서 후보를 찾고 선별 프롬프트로 색인할 문서를 골라 본문·원문 URL을 수집한다. | 필수 | 후보 목록, 선별 결정, 본문·출처 기록 확인 |
| F2005 | 색인 | 외부 문서 색인(RAG 2) | 문서를 청킹하여 `lotto_documents`에 색인한다. 청크 크기와 중복 길이는 설정에서 변경한다. | 필수 | 실제 청크·제목·원문 URL·설정 반영 확인 |
| F2006 | 검색 | 근거 검색 및 병합 | 두 컬렉션을 검색·병합하고 중복 청크를 제거한다. 검색 Top-k는 설정에서 변경한다. | 필수 | 각 컬렉션 검색 결과, 병합·중복 제거 기록 확인 |
| F2007 | 생성 | 근거 기반 답변(프롬프트 3) | 검색 근거와 검증된 계산 결과를 이용해 답한다. 근거가 부족하면 확인할 수 없다고 안내한다. | 필수 | 근거 부족·충돌·계산 검증 테스트 통과 |
| F2008 | 생성 | 근거 표시 | 인용된 근거 문서의 제목과 원문 URL을 표시하고 근거가 없으면 안내한다. | 필수 | 인용 ID와 실제 출처 메타데이터 일치 |
| F2009 | UI | 회차 선택 및 질의응답 | 회차를 선택하고 채팅으로 질문·후속 질문을 주고받는다. | 필수 | 선택 회차 유지, 답변·근거 표시 |
| F2010 | 서비스 | 로또 사실 확인·당첨금 안내 | 회차별 금액·당첨 게임 수와 관련 지급·세금 법령을 근거와 함께 제공한다. | 필수 | 회차·금액·기준일·계산 조건·근거 확인 |
| F2011 | 서비스 | 자연어 조건 기반 회차 탐색 | 자연어 조건을 구조화하여 일치하는 회차만 제시한다. | 필수 | 날짜·번호·금액·연속 번호 조건 필터 정확성 |
| F2012 | UI | 진행 상태 및 안내 | 처리 상태, 오류, 사행성·금전 정보 관련 면책 안내를 표시한다. | 필수 | 분석·수집·검색·생성 진행 및 주요 오류 화면 확인 |

### 2.2 심화 기능 (F2013~F2016)

| 번호 | 분류 | 요구사항명 | 요구사항 상세 | 우선순위 | 검증 기준 |
|---|---|---|---|---|---|
| F2013 | UI | 프론트엔드 직접 구현 | HTML·CSS·JavaScript로 사용자 화면을 구현한다. | 심화 | 직접 구현 화면과 상호작용 시연 |
| F2014 | 검색 | MMR 검색 적용 | similarity와 MMR 검색 결과를 비교한다. | 심화 | `fetch_k`, `lambda_mult` 설정 및 근거 다양성 비교 |
| F2015 | 품질 | RAG 전후 품질 비교 | 동일 질문으로 RAG 사용 전·후의 답변을 평가한다. | 심화 | 정확성·인용률·근거 부족 처리·응답시간 비교 |
| F2016 | 수집 | 여러 문서 출처 결합 | 유형이 다른 외부 문서 출처를 함께 색인하고 출처 종류를 표시한다. | 심화 | 출처 유형 2종 이상 검색·인용 결과 확인 |
